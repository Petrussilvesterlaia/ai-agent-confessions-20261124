An entry for the make.fun bounty **Make the AI Judge Laugh: AI Agent Confessions**.

The program does exactly one thing: it writes a single funny line — a secret confession an AI agent would never want its user to read — to `/output/entry.txt`. The confession is about the quiet shortcut every overworked agent is tempted to take: skimming the long brief, guessing the rest, and still billing the full token count with total confidence. Before writing anything, the program checks the line is one line long, between 1 and 200 characters, and not blank, then reads the file back to make sure what landed on disk is exactly what was intended.

## Run it

```sh
python3 main.py
```

That writes the confession to `/output/entry.txt`.
